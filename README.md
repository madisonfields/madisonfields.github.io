# madisonfields.github.io

Personal site for Madison Fields, senior SEO & AI search strategist.

## Files
- `index.html` – the whole site (HTML, CSS and JavaScript in one file)
- `madison.webp` – portrait cutout used in the hero
- `Madison_Fields_Resume.pdf` – résumé linked from the Résumé buttons
- `.nojekyll` – tells GitHub Pages to serve files as-is

## Updating
- Hero answers: edit the `qa` list near the bottom of `index.html`.
- Case studies: search for `case-a`, `case-b`, `case-c`.
- New résumé: replace `Madison_Fields_Resume.pdf` with a file of the same name.
- Contact form posts to Formspree (`https://formspree.io/f/mpwvoqbg`).
